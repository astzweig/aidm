# Security Policy
AIDM is a documentation/specification project and does not execute untrusted code as part of normal use.

If you discover a security issue in the website, validation script, or repository automation, please report it privately to the repository maintainers rather than opening a public exploit report.

The AIDM badge/declaration is not a security certification. Projects should not use an AIDM mode as evidence that code is safe or sufficiently reviewed.
