# Changelog
All notable changes to the AI Development Mode specification will be documented here.
The format is inspired by Keep a Changelog, and specification versions follow Semantic Versioning.

## [Unreleased]

### Planned
- Community feedback on mode boundaries and terminology.

## [0.1.1] - 2026-09-16
### Added
- Design principle stating the modes are an ordered spectrum of agency, not merit.
- "Why declare honestly" section explaining why accurate declarations benefit a project.
- "Relationship to other conventions" section positioning AIDM against commit trailers, PR disclosure, SPDX's AI profile, and binary badges.

## [0.1.0] - 2026-09-16
### Added
- Initial AIDM specification.
- Eight headline disclosure states: Autonomous, Supervised, Collaborative, Directed, Assistive, Incidental, None, and Mixed.
- Optional development profile.
- `.aidm.json` convention and JSON Schema.
- README badge convention.
- Static GitHub Pages website.
