# Roadmap
## 0.1 — Initial public draft

- Define headline modes.
- Define optional profile dimensions.
- Publish README badge convention.
- Publish JSON Schema and examples.
- Launch static documentation site.

## Before 1.0

- Collect classifications from real repositories.
- Test boundaries between Supervised/Collaborative and Directed/Assistive.
- Decide canonical domain and permanent schema URLs.
- Add translations based on community interest.
- Consider a small badge generator that does not require a build system.
- Document guidance for pull-request-level disclosures without turning AIDM into line provenance.
- Establish a compatibility policy for future optional profile dimensions.

## 1.0 criteria
AIDM should reach 1.0 when the headline modes have been tested across a sufficiently broad range of development workflows and the maintainers are confident their meanings can remain stable.
